# تجربة بوت SAU2030 محليًا

هذه نسخة تجريبية مستقلة. لم يتم الاتصال بحسابك أو تعديل البوت القديم.

## جرّب الشكل أولًا
افتح preview.html في المتصفح. المعاينة تعمل بلا توكن وبلا استضافة وبلا إنترنت، وتعرض نفس النصوص ومسارات الأزرار. شكل تيليجرام النهائي يعتمد على تطبيقك وثيمه. هذه المعاينة ليست اتصالًا بالبـوت الحقيقي.

## شغّل البوت في تيليجرام
تحتاج كمبيوترًا عليه Python 3.10 أو أحدث واتصالًا بالإنترنت. لا تحتاج مكتبات إضافية.
1. فك ضغط المجلد كاملًا.
2. في Windows افتح start.bat. في macOS أو Linux افتح الطرفية في المجلد وشغّل: python3 bot.py
3. ألصق توكن @SAU2030_bot في نافذة التشغيل المحلية. لن يظهر أثناء الكتابة ولن يُحفظ في الملفات.
4. افتح البوت في تيليجرام واضغط Start أو أرسل /start.
5. أبقِ الكمبيوتر متصلًا ونافذة التشغيل مفتوحة. Ctrl+C يوقفه.

إذا لم يكن Python موجودًا: حمّله من https://www.python.org/downloads/، ثم أعد التشغيل. على Windows فعّل إضافة Python إلى PATH أثناء التثبيت إن ظهرت.
لا تلصق التوكن في المحادثة أو GitHub. البرنامج يتحقق من أن اسم البوت SAU2030_bot قبل التعامل مع الرسائل. إذا وجد webhook قائمًا يتوقف دون تغييره. شغّل نسخة واحدة فقط.

## ما الذي يعمل؟
ترحيب، قائمة 7 تطبيقات، قائمة منتجات كل تطبيق، بطاقة منتج مصورة، طلب تجريبي، رجوع، دعم، معلومات. الأوامر: /start و/products و/help.
لا يتم تسجيل شراء أو تحصيل أموال أو حفظ بيانات العملاء. زر الطلب يوضح أنه تجريبي. لا توجد أسعار أو مدد أو مخزون أو إحصاءات مبيعات مختلقة.

## ما الذي نكمله لاحقًا؟
المنتجات المعروضة عينات وليست عروضًا للبيع. نحدد الخطط والأسعار والمدد والتوفر والضمان وحساب الدعم قبل تفعيل البيع. صور البطاقات الحالية تصاميم نصية بأسماء التطبيقات، وليست الشعارات الرسمية أو نسخًا مطابقة لصور المرجع.

شعارات داخل الأزرار: الكود يدعم icon_custom_emoji_id. يلزم تزويد كل تطبيق بمعرّف رمز تيليجرام مخصص صحيح وتفعيل custom_icons_enabled في catalog.json. وفق توثيق Telegram، تحتاج هذه الخاصية اشتراك Premium لمالك البوت في الرسائل المباشرة المدعومة، أو اسم مستخدم إضافي مشترى من Fragment. الإعداد معطل افتراضيًا؛ الأزرار تظهر بالأسماء إلى أن نوفر الرموز الصحيحة.
المصدر: https://core.telegram.org/bots/api#inlinekeyboardbutton

تعديل أسماء التطبيقات والوصف وحساب الدعم يتم في catalog.json ثم إعادة تشغيل البوت. المعاينة المرفقة لقطة من الإعدادات الحالية؛ لا تتحدث تلقائيًا عند تحرير JSON.
