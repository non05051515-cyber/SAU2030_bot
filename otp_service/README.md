# بوت أكواد VEXA المستقل

يستقبل العميل رابطًا خاصًا بطلبه، ويقرأ البوت رمز ChatGPT الجديد من بريد
مربوط ومصرح به. لا يستطيع البوت الوصول إلى بريد المورّد دون ربط أو تفويض.

## التشغيل

شغّل خدمة مستقلة من مستودع VEXA، بأمر البدء:

```sh
python -m otp_service.server
```

اربط مجلد تخزين دائم في `/data`. يعمل `/health` قبل ربط تيليجرام والبريد،
ويعرض هل إعداداتهما مكتملة. لا يبدأ استقبال طلبات تيليجرام دون التوكن.

## متغيرات خدمة الأكواد

| المتغير | الاستخدام |
|---|---|
| `OTP_BOT_TOKEN` | توكن بوت مستقل ينشئه صاحب المتجر في BotFather |
| `OTP_BRIDGE_SECRET` | سر عشوائي لا يقل عن 32 حرفًا، مشترك مع خدمة المتجر |
| `OTP_ADMIN_ID` | حساب الإدارة؛ الافتراضي حساب إدارة فيكسا الحالي |
| `OTP_STATE_PATH` | الافتراضي `/data/otp.sqlite3` |
| `GMAIL_OTP_USER` | البريد الذي يملك المتجر صلاحية قراءته |
| `GMAIL_OTP_CLIENT_ID` | معرّف Google OAuth |
| `GMAIL_OTP_CLIENT_SECRET` | سر Google OAuth |
| `GMAIL_OTP_REFRESH_TOKEN` | تفويض Gmail بصلاحية `gmail.readonly` |

بديل OAuth: `GMAIL_OTP_USER` و`GMAIL_OTP_APP_PASSWORD` لحساب Gmail
مصرح به. يجب أن تصل رسالة الرمز الأصلية أو تحويلها مع معلومات المستلم
والتحقق من المرسل إلى البريد المربوط. مجرد معرفة الإيميل لا تكفي.

## متغيرات خدمة المتجر

| المتغير | الاستخدام |
|---|---|
| `OTP_SERVICE_URL` | رابط HTTPS لخدمة الأكواد |
| `OTP_BOT_USERNAME` | اسم بوت الأكواد دون @ |
| `OTP_BRIDGE_SECRET` | نفس سر خدمة الأكواد |

في إعدادات المنتج فعّل «كود الدخول عبر Gmail». تؤخذ هوية العميل والبريد من
الطلب المسلّم وبيانات تسليمه، لا من نص يرسله العميل. إذا كان بريد التسليم
غير موجود أو تعذر الربط، يبقى زر طلب المساعدة اليدوي الحالي.

## حدود الاستخدام

- الحد الافتراضي رمزان لكل طلب، مع انتهاء صلاحية رابط الطلب.
- إعادة فتح الرابط لا تعيد عدّاد الاستخدام، ولا تمدد الصلاحية.
- لا يستطيع حساب تيليجرام آخر استعمال رابط العميل.
- ينتظر وصول رسالة جديدة 3 دقائق؛ انتهاء الانتظار لا يحسب محاولة.
- يتأكد قارئ البريد من المستلم والمرسل الموثوق وحداثة الرسالة، ويمنع إعادة إرسالها.
- إذا فشل إرسال تيليجرام بصورة مبهمة، يوقف إعادة الإرسال ويحجز محاولة
  لمراجعة الإدارة؛ ربما تكون الرسالة وصلت بالفعل. لا تُعاد رموز محفوظة تلقائيًا.

فحص الإدارة في بوت الأكواد: `/status`. كل الطلبات متاحة فقط للمنتجات التي
فعّلها صاحب المتجر. الرمز لا يُطلب من ChatGPT نيابة عن العميل؛ العميل يطلبه
من شاشة الدخول بعد الضغط على زر طلب الكود.
